# Customer Billing System 📋

This is a simple C mini-project to manage customer billing data using file handling.

 Features

- Add customer accounts with payment details
- Search customer by account number or name
- View customer status (Current, Overdue, Delinquent)
- File-based persistent storage using `file.txt`

 Technologies Used

- C Programming
- File Handling (Binary)
- Command Line Interface (CLI)
